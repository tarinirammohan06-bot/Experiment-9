Experiment 09: Custom Server and Node Modules

📌 Description

This experiment demonstrates how to create a custom HTTP server using Node.js and explore its built-in modules. It uses the http, os, path, and events modules to handle HTTP requests, retrieve operating system information, manage file paths, and handle custom events.

🎯 Objectives

* Create a custom HTTP server using the http module.
* Retrieve system information using the os module.
* Display the current working directory using Node.js.
* Manage and join file paths using the path module.
* Create and handle custom events using the EventEmitter class.

🛠️ Technologies Used

* Node.js
* JavaScript
* Built-in Node.js Modules: http, os, path, and events

⚙️ How to Run

1. Install Node.js on your system.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

node server.js

5. Open your browser and visit:
    http://127.0.0.1:3000/

✅ Expected Output

* The browser displays Hello, World!
* The terminal displays operating system details, CPU core count, the current working directory, and the joined file path.
* A custom event is triggered, and its message is displayed in the terminal.

📚 Learning Outcome

This experiment provides practical knowledge of creating an HTTP server and using Node.js built-in modules for system information, path management, and event handling.
